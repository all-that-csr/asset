Vol.5부터 매거진 큐레이션 레이아웃 3가지 변경 도입 예정.

1. **큐레이션 그룹핑**: 채팅방별(전체/지속가능경영/임팩트투자) → 주제별(정책·공시, 기업·사회공헌, 글로벌·환경, 임팩트·투자) 4개 그룹
2. **채팅방 출처 칩**: 각 큐레이션 카드 카테고리 태그 옆에 원래 채팅방 출처를 작은 칩으로 표시
3. **커뮤니티 토론 섹션**: 큐레이션과 놓치지 마세요 사이에 "이번 주의 대화" 섹션 신설 (테마색 #8B5CF6 보라)

**Why:** Vol.4까지 채팅방별 그룹핑이었으나, 독자 입장에서 주제별이 더 직관적이라는 판단. 커뮤니티 토론 섹션으로 참여 유도.
**How to apply:** Vol.4 콘텐츠로 샘플(매거진_v5_sample.html)을 먼저 만들어 레이아웃 검증 후 Vol.5부터 정식 적용.
