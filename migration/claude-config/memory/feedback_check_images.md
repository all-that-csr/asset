name: 매거진 생성 시 이미지 파일도 확인
description: CSR 매거진 생성 시 폴더 내 JPG/PNG 이미지도 반드시 읽어서 콘텐츠에 반영할 것
type: feedback
---

매거진 생성 시 폴더 안의 JPG/PNG 이미지 파일도 반드시 Read 도구로 확인할 것.

**Why:** Jong il Lee님이 매일 공유하는 행정안전부 "지방행정 여론·동향" 브리핑 등이 이미지로 저장되어 있는데, 이를 누락하면 콘텐츠 품질이 떨어짐. 사용자가 폴더에 함께 넣어둔 파일은 모두 의미가 있음.

**How to apply:** csr-magazine 스킬 실행 시 PDF뿐 아니라 JPG/PNG 파일도 Read로 확인. 정부 브리핑 이미지는 "주간 정책 브리핑" 별도 코너로 텍스트 요약하여 반영.
