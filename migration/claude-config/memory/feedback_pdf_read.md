---
name: PDF 파일 전부 읽어서 요약 품질 향상
description: 매거진 생성 시 폴더 안 PDF 파일을 모두 읽고 요약에 반영할 것
type: feedback
---

매거진 생성 시 대화 파일과 함께 폴더에 포함된 PDF 파일을 전부 읽어서 큐레이션 카드의 요약 품질을 높여야 한다.

**Why:** 대화 파일만으로는 기사/보고서 원문 내용을 정확히 파악하기 어려움. PDF를 함께 읽으면 핵심 수치, 기관명, 정책 내용 등을 정확하게 반영 가능.

**How to apply:** 앞으로 사용자가 대화 파일 3~4개를 폴더로 제공할 예정. 폴더 안에 있는 모든 PDF를 읽고 해당 내용을 매거진 요약에 반영할 것. HWP는 읽을 수 없으니 PDF 변환 요청.
