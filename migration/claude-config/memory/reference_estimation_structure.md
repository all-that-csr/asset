### 비용 산출 공식
1. 직접인건비 합계 = 각 항목별 (단가 × 투입기간MD × 투입율) 합산
2. 직접경비 = 별도 항목 (홍보물, 굿즈 등) — 없으면 "항목 없음"
3. 제경비 = 직접인건비 × 100%
4. 기술료 = (직접인건비 + 제경비) × 10%
5. 산출가 = ①+②+③+④
6. 제안가 = 만 단위 이하 절사, VAT별도 (5% 할인 적용하는 경우 있음)

### PM 투입율 기준
- 전체 프로젝트 기간 대비 3~10% 수준

## 견적서 구조 (간결형 — UNHCR 형식)
- 구분 / 항목 / 수량 / 단가 / 비용 / 비고
- 비고에 상세 내역 기술

## 참고사항 (공통)
- 유효기간: 견적일로부터 10~15일
- 지불조건: 계약시 협의
- 제작기간: 영업일 기준, 컨펌 지연 시 변동
