매거진 생성 시 Vol 번호를 자동으로 계산해서 적용할 것.

**Why:** 사용자가 매번 Vol 번호를 수동으로 지정/수정하는 번거로움 제거.

**How to apply:**
- 매거진 생성 전 `all_that_csr/` 폴더 내 기존 thumbnail.html 파일들을 확인하여 마지막 Vol 번호를 파악
- 새 매거진은 마지막 Vol + 1로 자동 부여
- 발행 이력 기준:
  - Vol.1: 260407 (2026년 4월 1주차)
  - Vol.2: 260413 (2026년 4월 2주차)
  - Vol.3: 260417 (2026년 4월 3주차)
