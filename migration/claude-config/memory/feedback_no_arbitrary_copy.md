---
name: feedback_no_arbitrary_copy
description: 디자인 작업 시 기존 문구에 임의 카피를 추가하거나 변형하지 말 것
type: feedback
---

기존 문구를 활용해달라고 했을 때, 임의로 새로운 카피를 만들어 붙이지 말 것.

**Why:** 사용자가 "즐거운 움직임이 곧 건강한 배움이 되는 시간"을 활용해달라고 했는데 "오늘도 신나게, 렛츠무브!"를 마음대로 추가해서 지적받음.

**How to apply:** 클라이언트 문구/카피 작업 시 원본 텍스트를 존중하고, 새로운 문구 추가가 필요하면 반드시 먼저 확인받을 것.
